# Agent Note: 工具分发门禁与每轮压力修剪

Status: proposed

[English](2026-11-06-tool-dispatch-gate-and-pressure-pruner.md) | 中文

## 问题

SOTA 计划的 P2 在同一个变更里包含两项彼此独立的工作：可执行的工具分发策略，以及出站上下文的 token 压力杠杆。两者目前都不存在。工具限制只把工具从模型可见集合中移除；直接或替代调用方仍可分发该工具，因此「隐藏」不等于「拒绝」。现有的工具结果修剪器只在压缩本身达到触发条件时运行，所以长会话可能在多个轮次中一直携带大体积工具结果而不被修剪。P1 已测得仅靠提示体积选择无法改变每请求 token 预算（0.45 %，见 outbound-governor 笔记）；剩余体积是会话历史，本变更通过工具结果内容来处理它。相邻提案：[recallable compaction](2026-07-06-recallable-compaction.zh.md) 关注让被遮蔽历史可召回；本变更不依赖它。

## 方案

两个可选的插件，不改变已发布默认值：

1. `@deepseek-ai/dsh-tool-dispatch-gate` 在 `tools/pre-execute` 上注册，把规范化后的工具名（NFKC、移除格式字符、去空白、转小写——绝不改写 `exec.name`）与精确条目或结尾 `*` 前缀的白名单比较；显式 deny 优先。`audit`（默认）把非允许决策记录为持久仅日志事件 `tool/dispatch-gate` 并委托；`enforce` 返回 deny 决策且不调用 `next()`，因此后续监听器无法批准该调用。12 个绕过向量已由测试覆盖，包括真实 Loader 编排。
2. `compaction-tool-result-pruner` 新增默认关闭的 `pressure: { maxContextTokens, pruneThresholdChars }` 块。配置后，`agent/pre-step` 监听器用注入的 token meter 测量会话，仅当超过 `maxContextTokens` 时，通过既有替换路径按压力阈值修剪当前工具结果节点；完整原文保留在日志中，`compaction/prune` 影子价格不变。

在 CH-040 的三个会话上用回放模拟测量（以日志中的提供方 usage 作为基线；被移除字符按 meter 的固定启发式计价；每次携带被修剪表面的后续请求都计入一次节省）：

| 策略 | `maxContextTokens` | `pruneThresholdChars` | head / tail | 节省 tokens | 占基线 |
|---|---|---|---|---|---|
| 保守（现有默认值） | 100 000 | 8 192 | 4 096 / 1 024 | 23 226 625 | **12,94 %** |
| 激进 | 40 000 | 3 000 | 2 048 / 512 | 36 870 187 | **20,54 %** |

只有激进策略能达到 −20 % 门禁，它每个工具结果大约保留 640 tokens；保守策略为 12,94 %。两者都未在已发布预设中启用，因此已记录快照不变。分发门禁对 token 没有影响（它是安全控制）。

## 已考虑的替代方案

- **默认强制** —— 拒绝：计划要求先经历审计期；没有观察窗口的默认拒绝会在第一天破坏合法工具。
- **用能力词汇代替规范化名称** —— 推迟：能力词汇需要当前消费者及其分组的证据；精确名称加显式 MCP 前缀通配符今天可审查。
- **降低现有压缩阈值而不是新增每轮触发** —— 拒绝：那会改变每个部署的压缩修剪行为，而且仍在等待压缩触发。
- **全局降低 `thresholdChars` 以获得激进效果** —— 拒绝：同样的形态会无条件改变压缩修剪；压力块让激进程度保持可选。
- **把激进策略当作默认值** —— 拒绝：用 20 % 的收益把结果修剪到 640 tokens 带有本变更无法测量的模型质量风险；它保持为带 kill criteria 的部署决策。

## 验收标准

- 门禁在 `enforce` 下拒绝、在 `audit` 下记录 12 个绕过向量，只记录非允许决策，且绝不让下游监听器批准被拒绝的调用。
- 未配置时压力触发器不添加监听器，只在超过 `maxContextTokens` 时修剪，原文保留在日志中，并且在多个步骤间幂等。
- 聚焦测试、typecheck 与文档门禁通过；在编排中启用触发器是另一个决策，因为它会改变模型可见结果与快照。

## 风险

- **激进截断带来的质量回退** —— 每个结果 2 048 + 512 个字符可能隐藏长输出的中段；触发器必须保持可选，并在工具调用重试或任务成功率回退时关闭。
- **模拟而非实跑** —— token 占比假设提供方 usage 会随被修剪上下文下降；它不能证明模型行为。实跑评估仍是启用的门槛。
- **审计体积** —— 门禁只记录非允许决策；需要完整调用遥测的部署应使用工具调用日志，而不是此事件。
- **压力时机** —— 触发器在 `agent/pre-step` 测量，因此作用于下一个请求；始终低于阈值的会话保持当前行为。
